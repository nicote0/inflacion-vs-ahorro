# M3 API — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** API HTTP de solo lectura (Fastify) con `/indicadores`, `/series/:indicador`, `/comparativa`, `/frescura` y `/simulacion`, documentada en `/docs`, que responde desde una foto de los datos en memoria.

**Architecture:** Workspace `api/`. `crearApp({ obtenerFoto, origenesCors })` arma la app sin escuchar. Cada endpoint es una función pura sobre la foto (`Foto`), que un cargador lee de Postgres y guarda 1 hora. La validación usa JSON Schema y la documentación OpenAPI se genera de esos schemas.

**Tech Stack:** Node.js 24 (ESM), Fastify 5.12, `@fastify/swagger` 9.9, `@fastify/swagger-ui` 6.1, `@fastify/cors` 11.4, `pg`, paquete `simulacion` (M2), `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-27-m3-api-design.md` (aprobado el 2026-11-27). Issues: #31, #32, #33, #34, #35 y #47.

## Global Constraints

- Solo lectura. Costo cero. Ninguna credencial en el código: `DATABASE_URL_POOLED` (o `DATABASE_URL` si falta) sale del entorno.
- Formato de error único: `{ "error": { "codigo": "TEXTO_EN_MAYUSCULAS", "mensaje": "texto claro en español" } }`.
- Un 500 responde siempre `ERROR_INTERNO` con el mensaje "Ocurrió un error interno"; el detalle va solo al log.
- Respuestas exitosas: `Cache-Control: public, s-maxage=3600, stale-while-revalidate=86400`. Errores: `Cache-Control: no-store`.
- Fechas `AAAA-MM-DD`, meses `AAAA-MM`. No se rellenan datos: donde falta, `null`.
- La simulación se calcula con `simular()` del paquete `simulacion`, nunca reimplementada.
- Mismo estilo de M1 y M2: ESM, textos en español, un commit por tarea con `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, push solo con OK de Nico.

## Review Focus

1. **Parámetro de más o repetido** (`?desde=2020-01&desde=2021-01`, `?foo=1`): 400 `PARAMETRO_INVALIDO`, no un 500 ni un parámetro ignorado en silencio. Test en la Tarea 1.
2. **Pedidos simultáneos con la foto vencida:** una sola lectura a la base, no una por pedido. Test en la Tarea 6.
3. **`hasta` posterior al último IPC en `/simulacion`:** 400 `PERIODO_FUERA_DE_RANGO` con el rango en el mensaje, no un error de la simulación. Test en la Tarea 5.
4. **Indicador con mayúsculas o espacios en `/series/:indicador`:** 404 `INDICADOR_DESCONOCIDO`, sin tocar la base. Test en la Tarea 2.
5. **Error inesperado cuyo mensaje contiene una URL o una contraseña:** la respuesta no la incluye. Test en la Tarea 1.
